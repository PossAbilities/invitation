# PossAbilities Invitations

A hosted PossAbilities invitation prototype for creating an event campaign,
previewing the email envelope, and showing an animated RSVP invitation page.

## Current Prototype

- Branded event builder using the PossAbilities colour palette and strapline.
- Editable event name, date, time, location, host, message, and card accent.
- Animated recipient preview with an envelope reveal and RSVP buttons.
- Guest list, email preview, and campaign response summary.
- Site-specific social preview image and metadata.

## Next Product Steps

- Add user accounts and role-based access.
- Store events, guests, invite links, RSVP responses, consent, and audit logs.
- Connect a transactional email provider for real sending, bounce handling, and
  unsubscribe support.
- Add privacy, retention, export, and delete tools before storing real personal
  data.
